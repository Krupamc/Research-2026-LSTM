Models:

The Prediction Models

This project's original purpose was to use a long short-term memory model (LSTM) to predict the wind conditions and compare it to using more mathematical approaches such as linear regressions and naive persistence models. However, the current prediction models on this site do not defaultly use the LSTM for reasons we will get into later.

What is an LSTM?

Glad you asked...(you will regret this). LSTM networks are a specialized form of Recurrent Neural Network (RNN), a neural network designed to process sequential data, maintain a “memory” of previous outputs, and predict sequential data. LSTMs store memory differently compared to other neural networks, which allows them to “recall”, “update”, or “forget” data through different logic gates. These gates regulate the flow of information, allowing the model to remember long-term patterns and train on large datasets without gradients (signals used to update network weights) decaying, a major disadvantage in typical RNNs. It was hypothesized that an LSTM using the previous 24 hours of observations would produce lower one-hour-ahead wind-speed and direction errors than linear regression and persistence.

Evaluation:

The naive and linear regression algorithms were tested along with the LSTM to verify the necessity of the deep learning model. A separate model was developed for each target variable. The most accurate of the three is used in the final program. The Mean Absolute Error (MAE) is calculated and noted for all the predictions compared to the corresponding hourly observations from the Stafford Weather Station, NJ, and then compared to find the most accurate prediction.

  • Wind-speed and gust-speed predictions were evaluated using MAE in mph.
  • Direction predictions were evaluated using circular MAE, which measures the shortest distance around the 16-bin compass.
  • Binary predictions were evaluated using MAE on the predicted 0/1 flags, precision, recall, and confusion matrices.
  • Upwelling detection could not be assessed in evaluation periods containing no labeled upwelling events.

Linear Regression and Naive Persistance:

  • Naive Algorithm: This algorithm assumes that the value presented/predicted before is correct and uses this value for its prediction. It also assumes that values change slowly over time.
  • Linear Regression Algorithm: This algorithm assumes that there is a linear relation between the input and output as the best-fit line for the prediction. In multiple-variable situations like this, it uses weighted sums of the current values.

Original Model Structure:

LSTM Input and Prediction:

  • After training, the LSTM used the previous 24 hours of weather data from the selected stations and buoys to predict conditions for the following hour. Windows crossing missing hours were excluded.
  • Each model contained a 32-unit LSTM layer followed by a 32-unit dense layer.
  • Output depended on the target: One numerical output for wind speed or gust, 16 class probabilities for directions, or one sigmoid (activation function like tahn) output (binary) for onshore and upwelling flags.
  • Models were trained using training data (80% training, 10% validation, 10% testing), while validation loss monitored performance and controlled early stopping.
  • Several training settings were adjusted to improve LSTM performance, including the following:
      Models were trained without shuffling, and validation loss controlled early stopping. Epochs were set for 100.
      • Epoch Number - The number of passes through a dataset.
      • Validation Split - Splitting Factor of how much of the data is set aside for testing to avoid over-fitting or making the model inefficient in predicting new data.
      • Shuffling - Whether or not the data is shuffled around to prevent over-fitting.

Naive and Linear Regression Input and Prediction:

  • The naive algorithm will only need to pull the last data point to predict.
  • The linear regression was trained with the same training data (Similar to the LSTM) but only needs a single hour of data to predict the next hour.
    • Separate linear regression models used the current hour’s observations to predict each target one hour ahead.
    • Models were fitted using the training data and applied to the held-out test period. (Same as LSTM)

Current Model Setup

  • Linear Regression: Wind Speed
  • Linear Regression: Wind Gusting Speed
  • Naive: Wind Direction
  • Derived from Direction Prediction: Onshore flag (binary)
  • No models were able to predict for upwelling events as there was only one upwelling events in the testing part of the dataset.
